# 月灯 MART · v2.0.0

基于 [Jasper-N/rainy-corner](https://github.com/Jasper-N/rainy-corner) 的原始 Three.js 场景。所有模型、纹理均由本地代码和 Canvas 生成；无后端、无 CDN、无构建步骤。保留原商店、路面、电线杆、斑马线、原始相机和拖动/缩放操作。

## 本地运行

安装 Node.js 22 或更新版本，在本目录执行：

```sh
node start.cjs
```

打开 http://127.0.0.1:8766/ 。模块需要通过 HTTP 加载，请勿直接以 `file://` 打开 HTML。

## 仓库版本与部署

本版本放在独立分支 `release/v2.0.0` 的 `versions/v2.0.0/` 目录，完整保留仓库根目录的旧便利店项目。`main` 和现有 GitHub Pages 部署保持不变。

- 本地：进入 `versions/v2.0.0/` 后运行 `node start.cjs`。
- 独立保存：保留版本分支即可继续迭代，不需要改动旧版。

- 请勿把新版文件复制覆盖仓库根目录，也不要把 Pages 源切换到版本目录来替代旧版。

实际运行只需 `index.html`、`scene.js`、`extensions.js`、`environment-state.js`、`controls.css`、`indoor-navigation.js`、`loading.js` 和 `vendor/`。无需构建或后端。测试、预览脚本与说明文件不影响静态部署。

## 操作

- 点击店门口的淡黄色呼吸光晕，或左下角“进入便利店”，进入顾客平视的室内。
- 门内同样有淡黄色呼吸光晕，转头看门并点击即可返回室外；左下角固定显示“返回室外”按钮，也支持 Esc。返回后恢复进店前的室外上帝视角、视野和缩放范围。
- 室内用方向键 / WASD 平滑移动，↑↓ 前后、←→ 左右平移，鼠标或触屏拖动转头；手机可按住右下角方向按钮移动。视线固定在地板上方 1.6 米，墙壁、货架、吧台和椅子阻止穿行，视角不能飞出店外。
- 右上角面板分别选择季节、天气、时段。手机默认折叠，点击标题展开。
- 室内点击饮料机可取罐装饮料，点击热水机有接水反馈。
- 原来的拖动、滚轮/双指缩放和双击重播组装动画仍可使用。

## 环境规则与同步

- 初始为秋季、雨、夜晚；保留原雨夜灯光、反射和背景参数。新增物体也会影响整体阴影及反射，因此不宣称整张画面逐像素相同。
- 夏季“雪”、冬季“彩虹”按钮置灰。先选雪再切夏季时自动改为雨；先选彩虹再切冬季时自动改为晴，并提示。
- “彩虹”代表雨后放晴，保留湿地；仅白天和黄昏可见。夜晚仍可保留该天气状态，但彩虹隐藏并提示。
- 室内和室外使用同一个 `Scene`、同一个状态仓库、同一套粒子和环境光。窗外是真实场景，没有第二份天空或预渲染图片。
- 切换环境时用与帧率无关的插值，约 0.8 秒接近目标；场景切换采用约 0.36 秒淡出和淡入，室内模型在遮罩期间分批建立。系统“减少动态效果”开启时缩短过渡。
- 室内保留原地板、玻璃、完整实体墙和屋顶，并补充内部天花板；仅替换原基础货架与冰柜。后墙、侧墙和天花板遮住外景，只有玻璃方向能看到外部真实街景。韩式杯面、袋面、零食、瓶装饮料、饮料机、饮用热水机、窗前吧台和高脚椅均保留。退出即释放新增室内几何、材质与贴图。

## 停车场反馈修订

- 左侧停车场从 5×12 扩为 8×12 个场景单位，宽度增加 60%，与原底座在 `x=-6` 直接拼接。
- 三个约 2.55 宽的车位并排停放三辆车，前方完整保留约 4 个单位深的行车通道；没有车辆堵在通道中。
- 自行车棚同步加宽至约 5.95，5 辆自行车间距扩大至 1.1。
- 四周低矮金属双横杆围栏，右侧留车辆入口和步行缺口；入口牌与地面箭头引导通行。原街区布局未移动。
- 雨雪粒子、湿地、积雪和照明覆盖扩建区域。

## 性能与验证

新增静态几何按材质合批，标签贴图复用；手机限制像素比 1.25、阴影贴图 1024、反射 512，并减少雨雪数量。原组装动画结束后缓存静态阴影，进入室内/返回时刷新；双击重播时恢复更新。室内外共用 renderer、camera；室外保留 OrbitControls，室内禁用环绕相机并使用独立的顾客移动逻辑，退出室内时去除交互对象并释放其 GPU 资源；页面真正离开时清理监听器、定时器、原场景与渲染器。

首次打开时，20 组原模型按原顺序分批构建，每批之间让浏览器绘制一帧，新增停车场、自行车和静态合批也分批执行；显示实际进度。重复几何和描边几何复用，描边材质共享；浏览器支持时使用异步着色器预编译。构建过程保持原组装动画，手机相机缩放在启动前设置，避免加载完成时视角跳变。此优化减少集中创建和首次着色器编译带来的停顿，不保证低配置设备完全没有长帧。
