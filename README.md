## 交互操作说明
- **拖动旋转**：按住鼠标左键（或单指拖动）360 度旋转观察模型
- **滚轮缩放**：滚动鼠标滚轮（或双指捏合）放大查看店内陈设与街角细节
- **重播动画**：双击画面可重新播放模型从地面逐件组装的入场动画
